**硬闸** = G1/G2/G3/G4/G8/**G9a**（任一明确不过 ⇒ 不可能 adopt）；
**软闸** = G5/G6/G7/G9b/G9c/G10/G11（不过 ⇒ `pending/evidence_pending`）。

### ★★ 必要条件：判据必须建立在【超额收益】之上（2026-10-06 实验得出）

设策略收益 $r_{jt} = w_t + \varepsilon_{jt}$（$w$ = 基准，$\varepsilon$ = 策略特有）。
**若把 G6/G9a/F1 直接作用在绝对收益 $r$ 上**，市场波动会主导总波动，
使绝对夏普被系统压低（实测：$\sigma(w)/\sigma(\varepsilon)\approx3$ ⇒ t 值被压缩约 3 倍），
**后果是四条判据把全部候选都拦掉——包括训练段 t=4.0 的真信号（拦截率 100%）**。

⇒ 判据一律作用于 **$x_{jt} = r_{jt} - w_t$**（DSR 即信息比率）。
**该失效模式是静默的**：症状表现为"框架什么都没找到"，极易被误读成"这批候选都不行"。
**部署自检动作**：打印**逐条判据的拦截率**（真信号列 vs 噪声列各是多少）——
若真信号列的拦截率也接近 1，就是这条错了。

★ **`pass = None`（未提供/不适用）既不算过也不算不过** —— 只有明确的 `False` 才阻断 adopt。
但**未经前向体检**（F 组全 skip）会封顶 `pending`。这条语义由 `would_adopt()` 单点实现，
`decide()` 与 `protocol_checks()` 共用，防止两处漂移（先例 P-13）。

### ★ 闸门有效性的实测边界（供用户判断"该不该开闸"）

注入式实验（29 只真实 ETF 标定的策略族面板 + 合成独立面板，各 400 次重复）实测：

| 训练段真信号 t | 纯搜索 FDR | 闸门 FDR | 闸门采纳率 | 建议 |
|---|---|---|---|---|
| ~1.0 | **0.39~0.42** | **0.000** | 1.2%~1.7% | 用闸门（精度优先），但要知道几乎什么都过不了 |
| ~1.5 | **0.18~0.19** | 0.000~0.034 | 6.8%~7.3% | 用闸门 |
| ~2.5 | 0.018~0.020 | **0.000** | 39% | 用闸门（性价比最高的一档） |
| ~4.0 | 0.000~0.003 | 0.000 | 98% | **不必用**（纯搜索已够，闸门无增量） |

⇒ **闸门是"精度装置"不是"收益装置"**：它把假发现率压到 0，代价是采纳率大幅下降。
**t > 2.5 时它是纯负担**。

## 二、F0–F6 前向体检组（v2.0 新增，缺体检 ⇒ 判决封顶 pending）

| # | 名称 | 输入字段 | 判据 | 不过的后果 |
|---|---|---|---|---|
| F0 | 口径钉死 | `fwd.panel_md5` + `fwd.caliber{adjust,asof,cost,universe}` | 指纹 + 四要素齐全 | 结论不属于当前口径，不得采纳 |
| **F1** | **样本量算术** | `fwd.{n_obs,mean,sd}` | **N\* = ⌈(2σ/μ)²⌉**；n ≥ N\* | **n < N\* ⇒ 只许「未检出」（pending/not_detected）** |
| F2 | 选择自由度诊断 | `fwd.per_day_max_candidates` | 单日候选 > 1 | ≤1 ⇒ 零自由度：**这不是选股策略而是事件过滤器**，随机对照不可测，且「加因子/改排序/调 topK」类优化**在定义上无效** |
| F3 | 前向优先排序 | `fwd.rank_key_source` | = `train` | = `holdout`/`full` ⇒ **invalid**（作弊键） |
| F4 | 参数平台 | 复用 G6 | 同 G6 | 同 G6（不重复计入） |
| **F5** | **差异笔集合审计** | `fwd.diff_trades.{added,removed}` | 两组 95%CI 均不含 0 | 任一含 0 ⇒ **改动未被证明**，不得宣称「提高了收益」 |
| **F6** | **留一笔 / 留一事件段** | `fwd.loo.{total,ex_best}` | `ex_best > 0`（当 total > 0） | 剔最好一笔后翻负 ⇒ **单笔独扛**，不得当规律 |

**μ ≤ 0 的特例**：`N*` 无定义（无穷）。引擎改用「n ≥ 30 才允许判 `reject`」——
即**样本足够大且方向为负**才判死，否则仍是「未检出」。

### F1 · N\* 公式与判死/判活

```
N* = ⌈(2σ/μ)²⌉        μ=逐笔净收益均值, σ=逐笔净收益标准差
判死：到 N* 笔时 95% CI 上界仍 ≤ 0        ⇒ reject
判活：到 N* 笔时 95% CI 下界 >  0         ⇒ 可 adopt
未到 N*：一律「未检出」——禁止判死，也禁止判活
```

打板线一个月约 2 笔 ⇒ N\*=30 要 15 个月，N\*=90 要 3.75 年 ⇒ **「影子盘两个多礼拜没赚」信息量为零**。

### F5 · 差异笔集合审计（最锋利的一把刀）

```python
def tkey(t):  return (str(pd.Timestamp(t["entry_day"]))[:10], t["code"])
kb, kc = {tkey(t) for t in base}, {tkey(t) for t in cand}
added   = [t for t in cand if tkey(t) not in kb]   # 改动"新增"的笔
removed = [t for t in base if tkey(t) not in kc]   # 改动"去掉"的笔
for arr in (added, removed):
    lo, hi = block_bootstrap_ci([t["net"] for t in arr], L=5)   # moving-block 95%CI
    p = signflip_p([t["net"] for t in arr])
    # CI 含 0 ⇒ 这批差异笔与「不改」统计无区别 ⇒ 改动未被证明
```

★ 为什么比「训练段/留出段两列」更强：实测某轮 8 个日级闸门里 **4 个**在纸面上"两段同向改善"，
差异笔审计把其中 **2 个**打回原形（CI 含 0）、另 **2 个**暴露为有害（剔掉的恰是 +4.8%/+5.0% 的赚钱笔）。
**只看两列会把 4 个假改善全部放行。**

### F6 · 留一笔（leave-one-trade-out）

```
loo_i = prod(1+rr for j≠i) − 1     # 把第 i 笔剔掉
报 min/max LOO 与「剔最好一笔后」
判据：剔最好一笔后翻负 ⇒ 该结论由单笔独扛，不可当规律
```

实测（某 ETF 腿训练段）：5 个池里有 **3 个**「剔最好一笔后翻负」，
且**所有池的"最好一笔"都是同一天进场**（9·24 行情启动）⇒ 「池扩容更好」里有一大块是**同一事件的重复计量**。

## 三、G9 · Deflated Sharpe Ratio

```
SR0 = sqrt(Var[SR]) · [ (1−γ)·Φ⁻¹(1−1/N) + γ·Φ⁻¹(1−1/(N·e)) ]      γ=0.5772…（Euler–Mascheroni）
白噪声零假设：Var[SR̂] ≈ 1/(n−1)（单观测口径）
年化换算：×sqrt(ppy)，ppy = A股242 / 美股252 / BTC365（context.ppy，默认 252）
DSR = Φ( (SR̂−SR0)·sqrt(n−1) / sqrt(1 − γ₃·SR̂ + ((γ₄−1)/4)·SR̂²) )
```

**首版实现踩坑（已写进 selftest）**：把 Φ⁻¹(1−1/N) 写成 Φ(1−1/N)、尺度误乘 sqrt(n)，
SR0 被灌大一个数量级 ⇒ **真效应被全灭**。分位数 vs 分布函数、单观测 vs 年化口径，改公式必须重跑 selftest。

**已知局限（必须随 DSR 一起报）**
- `Var[SR]` 用白噪声近似（1/(n−1)）会低估「策略族间真实方差」——能拿到各试错的 SR 序列时用经验方差替代。
- PBO/CSCV 在 T≤1000、N≤40 时噪声带可达 [0.05, 0.88]，**判据是「落在带内」而非「等于 0.5」**。
- `trials` 必须是**台账全量**（含被你忘掉的那些尝试），少报 = 给自己放水。

## 四、FPS · 稳健度分（因子层，`scripts/fps_factor.py`）

```
FPS = 均值( R1 | R2 | R3 | R4 | R5 )      ← ★ 五个分量全部只用【训练段】可算
  R1 训练段为正      ：训练段总收益 > 0
  R2 参数平台        ：同族 ±1 档邻居中训练段为正的比例
  R3 随机分位        ：训练段读数在同闸门随机零分布中的分位 / 100   ← 只能训练段！
  R4 训练 Calmar > 0
  R5 样本量          ：min(1, 训练段笔数 / 10)
```

★ **铁律**：`R3` 只能用**训练段的零分布**。用留出段零分布算 R3，FPS 本身就变成前向偷看。

**实测效果（29 只 ETF / 746 日 / 300 组配置）**：按训练段收益 Top10 ⇒ 留出段中位 +60.57%、跑赢基线 **1/10**；
按 FPS Top10 ⇒ **+121.41%**、跑赢 **5/10**；两榜交集 **0/10**。
⚠️ **必须同时报的负面**：FPS 的档位划分（merged/suspended/rejected）**不能**拉开前向胜率
（merged 档跑赢基线 61%，与全网格 61% 持平）——**它只在榜单顶端有区分度**。

## 五·C、新增三闸的实测依据（v2.2）

| 闸 | 为什么这么定 | 实测证据 |
|---|---|---|
| **G9b PBO** | 曾想做硬闸，但校准发现**单次 PBO 的标准差 ≈ 0.26**（T=256/N=12/S=8，40 次重复的均值 = 0.501）。噪声带这么宽的量**不能单独否决** | `overfit_metrics.py --selftest`：40 次噪声均值 0.501、单次 sd≈0.26；含真信号列 PBO=0.000 ⇒ 方向性有效 |

| **G11 面板 IC** | 文献（QuantaAlpha IC 0.1501 / FactorMiner IC 8.25%）全部以 IC 为通用语言；且面板级样本效率远高于逐笔 | 本项目 `train_only_gate_pool_factor_study.py` 已实现 IC/增量 IC/top1 前瞻 |

## 六、停止语义

停止 ≠ 证明没有 alpha。汇报措辞：「**继续搜索的期望产出已低于成本**」，并附 trials 总数与 DSR 带宽。
