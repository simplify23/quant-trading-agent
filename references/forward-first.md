# references/forward-first.md —— 前向优先 · 反自欺手册

> **一句话**：在讨论「这个策略好不好」之前，先证明**你能不能测出来**。
> 测不出来的时候，说「有效」和说「无效」**都是错的** —— 正确答案是「**未检出**」。
>
> ⚠️ **关于本文中的数字**：均为某内部量化研究项目的**实测读数**，已脱敏（不含标的、参数、账户与收益承诺），
> 仅用于说明方法论。它们是**证据**（且大量是负面证据），不是业绩展示。**不构成投资建议。**
>
> 引擎侧的机械化：`fwd` 段（F0–F6）与 `reason_bucket=not_detected`。本手册是人工执行版与解释层。

## 一、通俗名词表

| 名词 | 通俗说 | 为什么重要 |
|---|---|---|
| **前向段 / 留出段** | 你没碰过的那段历史。像考试里老师没给你答案的那道题 | 用它验才算数；用它选就等于偷看答案 |
| **训练段（IS）** | 你拿来调参的那段历史 | 一切「优化」都发生在这里，所以这里天然好看 |
| **N\*** | 证伪阈值。**N\* = ⌈(2σ/μ)²⌉** | 回答「要攒够多少笔才能把噪声和真效应分开」。没到 N\*，两笔为负 = 零信息 |
| **ρ（可迁移性）** | 秩相关：**历史上排在前的，未来是不是还排在前面** | ρ<0.3 ⇒ 用这个指标选参≈抽签 |
| **口径指纹** | 数据 + 复权 + 时点 + 成本 + 标的宇宙，一起算出的 md5 | 口径一改，旧结论**不再属于当前口径** |
| **前视** | 用了「当时还不知道」的信息 | 最典型：今天收盘的信号赚今天的钱。正确写法 `pos = signal.shift(1)` |
| **随机对照** | 随机选标的，看策略能排到第几名 | ★**必须闸门匹配**（见 §三.1） |
| **零分布 / 分位** | 随机对照跑出来的那堆结果；策略落在第几分位 | 分位 ≥ 95 才算越过噪声带 |
| **选择自由度** | **每个决策时点有几个候选可选** | 只有 1 个 ⇒ 「随机选」与「按分排序」数学上**完全一样**，跑随机对照会给出**假分位** |
| **moving-block bootstrap** | 把成串的收益整块重采样 | 笔与笔不独立，i.i.d. 会把相关抹掉、区间偏窄 ⇒ **报区间一律用它** |
| **sign-flip** | 假设每笔正负号可随机翻，看原结果多极端 | 便宜、不需引擎，回答「这串正负号是不是被挑出来的」 |
| **可分辨性分层** | 层内均值极差 ÷ 层内平均标准误 | <2 ⇒ 配置间差异小于噪声，**排序根本不可分辨**，此时 ρ≈0 是「测不出」不是「不迁移」 |
| **FPS（稳健度分）** | 五个「只反映稳健性」的分量取平均，**全部只用训练段算** | 换掉「历史最赚」这个目标，前向存活率才会提高 |
| **参数平台** | 好参数周围一圈邻居是不是也好 | 单点最优 = 噪声；要的是**连续**正向区间 |
| **三态判决** | `merged` 通过 / `rejected` 有证据反对 / `suspended` 不可判定 | ★**落在噪声带内是 `suspended`（未检出），不是 `rejected`（无效）** |
| **数据可用性伪影** | 规则"改善"其实来自**早期年份该变量没有历史值**、被保守语义整段拦掉 | 永远无法前向复制。判别法：把「历史不足就拦」切成「不拦」，差值就是纯伪影 |
| **传导检验** | 日级/组合级的预测量，能不能解释**策略自己那一笔** | 日级显著**不蕴含**逐票可用，甚至可能反向 |
| **目标粒度** | 你要预测的是"日"还是"笔" | 粒度一变就是**另一个问题**，效应不自动传导 |
| **差异笔集合审计** | 把改动"新增/去掉"的那些笔单独拎出来测 | ★最锋利的一刀：收益变好到底来自哪几笔？CI 含 0 ⇒ 改动**未被证明** |
| **N_eff** | 有效独立样本数（不是条数） | 高度相关的标的放在一起，名义 4 只可能只有 1.4 只的分散度 |

## 二、六道闸门（顺序不可颠倒）

```
G0 口径钉死 + 可复现锚点    没有指纹的结论，先别谈好坏
G1 样本量算术（N*）         先算「你能测出的最小效应」，再谈测到了什么
G2 随机对照零分布            先做「选择自由度诊断」，再谈分位
G3 前向优先排序              选优键禁止用全期
G4 参数平台（连续双正区间）   单点最优 = 噪声
G5 机制必填                  写不出机制 = 不通过
G6 三态判决 + 证伪清单        merged / rejected / suspended
```

| 三态 | 含义 | 下一步 |
|---|---|---|
| `merged` | 全部闸门通过 | 立刻复验 + 记回滚点 |
| `rejected` | **有证据反对** | 写入已证伪清单，禁止重复投入 |
| `suspended` | **样本/证据不足，不可判定** | 写明「需要什么新信息维度」 |

★ 效应落在噪声带内 ⇒ `suspended`（测不出），**不是** `rejected`（无效）。
**把「测不出」当成「没用」= 永久关掉一个可能有效的方向。**

## 三、最容易犯的错（都踩过，按严重度排）

### 3.1 随机对照不匹配闸门 ⇒ 结论会反过来
无闸门随机 +17.9% vs **闸门匹配随机 +10.4%**。留出段是牛市，满仓随机更占便宜
⇒ 无闸门对照会把「闸门在熊市省下的跌幅」错记成「选赛道的功劳」。

### 3.2 ★ 选择自由度诊断（跑随机对照**之前**必须先做）
```python
per_day = Counter(n_candidates(d) for d in days)
# max(per_day) <= 1  ⇒ 零排序自由度
```
| 诊断 | 含义 | G2 怎么办 |
|---|---|---|
| ≤1 | **这不是选股策略，是事件过滤器** | **G2 不可测**（不是"没做"是"不存在"）；同时宣告所有「加因子/改排序/调 topK」的优化**在定义上无效** |
| >1 | 有排序自由度 | 正常跑 `rank_key` / `rand_pick` 对照 |

★★ **诊断必须复刻引擎的「完整控制流」**：只复刻选股条件、漏掉日级 gate 会得到假值
（实测：漏日闸得「100 天有候选、5 天有 2 只」；补上日闸后是 **71 天各 1 只、0 天 ≥2 只**，而那 5 个"并列日"**恰好全被日闸挡掉**）。
**自证动作**：把"候选日数"与引擎实际成交日数对拍 —— 应满足「候选日 ⊇ 成交日」，差额只由槽位/一字板解释。

★ **`topk` 语义陷阱**：`topk=k` 通常是「同时开 k 个仓位槽」，**不是**「取第 k 名」。
要检验"只取第 r 名"必须**显式构造**（每日排序后只留第 r 个再喂回引擎）。

### 3.3 训练段「巨大优化」在留出段反向
实测：某开板退出规则 训练 +0.08%→**+3.17%**（看着巨大），留出 +5.25%→**+3.47%**（实际恶化）。
**纪律**：任何单旋钮结论必须同时报两段并标注同向/反向。某线 9 个旋钮里 **5 个方向相反** ⇒ 单向调参基本是噪声。

### 3.4 ★ 规则的「改善」可能 100% 来自**数据可用性伪影**
**标准检查（三条，缺一即不可采信）**：① 分年拆解（差异集中在某一年 ⇒ 可疑）；
② 看「留出段剔除 n」（一笔没拦住 = 根本没被验证）；③ 看被剔集合的 95%CI 与 sign-flip p（**CI 含 0 ⇒ 与不剔没有区别**）。
实测：某状态闸 Δn=9 笔 100% 落 2023、留出段剔除 **n=0**、被剔 18 笔 CI 含 0、p=0.624 ⇒ 判决 **suspended**（保留但标注伪影来源，禁止宣称有效）。
★ **通用形态**：任何带「冷启动 / 历史窗口不足 / 样本不足就保守处理」语义的参数（`insufficient:"block"`），
都会表现为「早期年份被整段拦掉」⇒ 天然产生漂亮历史，**且永远无法前向复制**。
**排查动作**：把该语义切成 `pass`，两者的差就是纯伪影。

### 3.5 ★ 目标粒度一变，效应可能不传导（日级 ≠ 逐票）
实测：日级（891 日）ρ 训练 +0.336 → 留出 +0.265、置换 p=0.0000 ⇒ **merged**；
但传导到策略自己 63 笔 ⇒ 全段 ρ **−0.225**、**AUC 0.368**（<0.5）；高温笔封板 45%/单笔 +0.50% ←→ 低温笔 72%/单笔 **+5.81%** ⇒ **反向**。
**机制**：`topk=1` 按分取第一 ⇒ 高温日选中的只是强票里的平平一个；低温日能过阈值的才是鹤立鸡群（**条件截断**）。
★ **纪律**：日级信号 merged **不等于**可接交易动作；只可做描述性环境提示，除非传导检验也同向显著。

### 3.6 ★ 分离一个规则的贡献时，别动会驱动其他逻辑的参数
`run_regime(days=...)` 里的 `days` 不只控制"哪些日有信号"，还驱动**退出日程** `later_of()`
⇒ 用 `days` 过滤冷日会**连卖出时点一起改**。**正解**：找到与目标闸门**控制流同构**的注入点：
```python
by_day_gated = {d: ([] if d in cold_days else lst) for d, lst in by_day.items()}   # 零改动冻结引擎
```
**等价性必须自证**：找一个引擎/文档里已有的读数当锚点，逐位一致才算成立。

### 3.7 ★★ 差异笔集合审计 —— 「改善」的来路必须先证明
```python
def tkey(t): return (str(pd.Timestamp(t["entry_day"]))[:10], t["code"])
kb, kc = {tkey(t) for t in base}, {tkey(t) for t in cand}
added   = [t for t in cand if tkey(t) not in kb]
removed = [t for t in base if tkey(t) not in kc]
# 任一组的 moving-block 95%CI 含 0 ⇒ 该改动【未被证明】，不得并线
```
实测 12 个候选里 **10 个 CI 含 0**；剩下 2 个"可分辨"的，剔掉的恰是**赚钱的笔**。
★ 实测某轮 8 个日级闸门里 4 个纸面上"两段同向改善"，差异笔审计把 **2 个打回原形、2 个暴露为有害**。

### 3.8 ★ 两个"看起来像改善"的记账陷阱
- **链式净值不是同风险比较**：放宽闸门让链式 +446.3%→+748.6%，但新增 22 笔单笔 +3.18%（基线 +3.20%）
  ⇒ 净值涨是**多下了 22 次注**，同时 mdd −47.77%→**−55.31%**。**规则：比链式净值必须同时报单笔均值与 mdd。**
- **排序键的差异可能 100% 落在留出段** ⇒ 训练段"看不见"排序键好坏 ⇒ 任何"训练段选优排序键"原理上就选不出来。
  **规则：先看"两段是否都能看见差异"，再谈 ρ。**

### 3.9 ★ 分段口径：**分段独立回测 ≠ 全段 nav 切分**
| 口径 | 做法 | 回答的问题 |
|---|---|---|
| **分段独立回测** | 在 `[a,b]` 子区间重新起跑（nav 从 1.0） | 「如果我从 b 那天才启用这条腿」 |
| **全段 nav 切分** | 全段跑一次，看各时间段贡献 | 「如果我一开始就在，各段贡献多少」 |

数学上 `(1+r_train)×(1+r_test) ≠ (1+r_total)`（实测 2.5896 vs 2.4072）。
**规则**：自证锚点必须**用产出报告时的那套口径**；报告显式写明用哪种；
独立回测下**分段笔数之和 ≠ 全段笔数**（段边界持仓切分不同）—— 正常现象，不是 bug。

### 3.10 多折 walk-forward 是**稳定性诊断**，不是前向证据
所有折由**同一批历史数据**构成 ⇒ 折的划分**不产生新信息**。真正的前向证据只有**未来新产生的样本**。
✅ 用途：看某配置是否「只在某一折好看」。❌ 不能：用它挑选配置。
★ **副产品（最有价值）**：折里偶然出现的**下跌区间是宝** —— 实测某折基线 −2.79% vs 无闸门 −28.74%
⇒ 闸门价值 **+25.96pp** 第一次在下跌段被直接看到（而训练/留出两段因留出段整体是牛市反而把它**掩盖**了）。

### 3.11 ★★ 零分布的**候选集口径** —— 不写清楚会差出 10pp
实测同一策略 p29/池MA100：公平口径分位 **92.7** ↔ 冻结口径 **96.3**，"过不过 95"的结论直接翻转。

| 口径 | 做法 | 随机能不能进「热身期」 |
|---|---|---|
| **公平口径**（推荐） | 随机只在**因子有效掩码**内抽（`np.isfinite(score)`），与策略同机会集 | ❌ 不能 —— 与策略一致 |
| **冻结口径**（很多旧脚本） | `pick = rng.integers(0, n_cols)`，可抽全列 | ✅ 能 —— 因子需 20~60 根才可算，前 25 天策略进不去、随机能进 |

冻结口径**给随机一个更差的机会集**，把策略分位系统性抬高约 5pp。
★ 顺带工程收益：传 `rand_valid` 掩码能**顺手消灭 NaN 污染**（抽到中途缺数据的列会让整条 NAV 变 NaN）。
★ 闸门广播语义要分清：**1D 标量闸门广播成全列（旧语义）**，**2D 才是逐标的闸门（新语义）**。

### 3.12 ★★ 留一笔 / 留一事件段 —— 「剔除最有影响的那一个，结论还在吗」
实测（某 ETF 腿训练段）：5 个池里 **3 个**「剔最好一笔后翻负」（+18.8%→**−8.5%**、+32.7%→−10.0%、+2.6%→−21.7%）；
且**所有池的"最好一笔"都是同一天进场**（9·24 行情启动）⇒ 「池扩容更好」里一大块是**同一事件的重复计量**。
（另：`pLiq` +50.0%→剔后 +20.4% 仍正 ⇒ 未翻负的那个可以继续讨论。）

**做法（都是 10 行代码）**：① 留一笔 `loo_i = prod(1+rr) − 1`，报 min/max LOO 与"剔最好一笔后"；
② 留一事件段（把「状态=1」的连续交易日聚成段，逐段剔除）。
**判据**：剔最好一笔后翻负 ⇒ 单笔独扛，不可当规律；**最差段极差 ⇒ 方差极大，方向可留意但不能当规则**。
★ 面板级检验（几万观测、t 值几十）最容易在这里翻车 ⇒ **`t_adj` = 先按日聚类再除 √h**（≥2 强 / 1~2 弱 / <1 不可判定）。

### 3.13 ★★ 「名字命中关键词」建池 ⇒ 必须去污，去污会改变结论
实测：`EXCLUDE` 已排「港股/恒生/黄金/豆粕/白银」，**但漏了「沪港深」和「期货」**
⇒ 混入 2 只商品期货 ETF + 7 只沪港深 ETF，而**那两只商品期货恰好被策略实际选中过**（+2.37%/+0.79%/+4.17%）。
**规则**：① 建池后必做**污染体检**，逐只打印（不要只报数量）；② 别只看名字（同名赛道可能有多只 ⇒ **伪分散**，按 `sector` 归类去重）；
③ ★**去污是有成本的**（实测 +51.2% → +35.6%）⇒ **报告必须同时给去污前/后两列**；④ 否定词表要**回写进数据层**。

### 3.14 ★ 训练段太短时的正确打法：别拼组合级，去做面板级
`训练段交易日数 / 最短持有` ⇒ 上界笔数；**上界 << N\* ⇒ 直接宣布组合级不可判定**，别浪费时间调参。
改做：**因子截面 IC**（日频 Spearman → t→t+h，报 IC 均值/t_adj/IC-IR/胜率）、
**增量 IC**（对其余因子做秩空间回归取**残差 IC** ⇒ 去冗余的正规判据）、
**信号日 top1 的前瞻收益分布**（比逐笔回测强 30 倍样本）、**状态 × 前瞻收益的 2×2 交叉**。
实测发现：**所有池所有闸门下 top1 均值全为负，而组合回测全为正** ⇒ 钱不是从"选对 top1"赚的，是从持有规则赚的。
★ 「不能碰留出段」的正确实现不是"不打印留出段"，而是**"留出段从未进入内存"**（物理截断 + assert）。

### 3.15 ★★ 「换载体」类实验：两个池的**列号索引空间会碰撞**
A 池和 B 池的列号都从 0 开始（实测 ETF∈[0,29)、个股∈[0,1171)）。
成本函数写成 `cost(c) = 0.20% if c in stock_cols else 0.06%` ⇒ **前 29 个 ETF 全被误按个股成本计价**，
而且自证用的是"全 ETF 成本"那一版 ⇒ **自证照过、错误静默**。
**规矩**：① 载体一律编码成一个整数（`ETF → -(cl+1)` 负 / `标的 → j` 非负）；② 自证要比**逐日净值最大相对误差 < 1e-12**（不能只比总收益）；③ 成本函数必须写进自证路径。

### 3.16 ★★ 候选池里**每个**候选都要单独过闸 —— 只审「头条候选」等于没审
实测：一轮 6~12 个候选，只对最亮眼那个做差异笔审计 ⇒ 结论会写成"载体切换有效但未证明"；
**全审之后才能说「没有任何一个模式被证明」**，并发现：
点估计最好的那个 **mdd 从 −19.5% 恶化到 −33.6%（近翻倍）**、**中位数 ≪ 均值**（+0.32% vs +2.77%）、
**换一个同族定义就崩**（"龙头"从 new_high 最强改成成交额最大 ⇒ Calmar 1.93 → **−0.12**）。
⇒ **对定义敏感 = 过拟合的直接指纹**，比 CI 更早暴露问题。
**规矩**：候选表**每一行**都要有 `n_diff / 均值 / 中位 / 95%CI / N* / 判定` 六件套。

### 3.17 ★ 三段式（前段 A → 中段 B → 后段 A）的窗口假设要单独验
用户给的是**分段假设**，而回测只能给**整笔差异**；整笔为正就被当成"分段假设成立"。
**规矩**：把每个窗口按**同一口径**分别算 A/B 载体的平均收益，直接摆「前/中/后 × 两载体」表。
实测：**中段（唯一真正换成龙头的窗口）差值最小（+1.01%，胜率 52.6%）**，前段与后段（对照）差值反而更大
⇒ **用户的窗口假设在数据上不成立**，整笔 +2.77% 全靠"整段都换龙头"撑着。

### 3.18 ★★ 「改池」之前先测**池构成敏感度** —— 敏感度大于改动幅度 ⇒ 不可判定
① **去污词表自己也要审**（实测把「中证800」加进宽基排除组，误挡了 4 只**行业基金**）；
② **去污前后两列都报**，并留一个"两边都在"的池做交叉自证（实测某池两次独立运行得到**逐位相同**的 +35.5613%，
一次同时验证了「引擎确定性」与「去污没碰到别的列」；反过来若某个未动过的池变了，说明改动**溢出了**预期范围）；
③ ★**先测敏感度再谈结论**：只改少数几只成员看读数摆多少 ——
实测只去 9 只 ⇒ 链式 **−15.61pp**；去 14 只 ⇒ −16.67pp、随机分位 96.6 → **91.5**（掉出 95）、"剔最好一笔"从 +9.62% 塌到 **+0.06%**。
**判据**：`|Δ收益| ≥ 少数几只成员带来的敏感度` ⇒ 结论**不可判定**，
正确说法是「**这个池对成员构成极度敏感，所以"改池更好"这句话本身没有被检验**」，
**不是**「改池更好，只是样本不够」。

**工程护栏（改数据层时顺手加，成本极低）**
- 若"现役面板"与"冻结基准"**逐字节相同**（同 md5）⇒ 全量重建脚本**默认拒写**，必须显式 `--force`。
- 建池后断言"入选名字不得命中排除词"——命中即**拒绝落盘**（命中 = bug，不是 warning）。
- 提供 `--audit`（逐只打印"谁被哪个词挡住"）与 `--prune-raw`（离线收紧缓存 + 自动备份 + 落剔除清单）。

## 四、十一条「不许」

1. **不许用全期指标选优。**（含留出段 = 作弊键）
2. **不许用不匹配闸门的随机对照。**（会把闸门功劳记成选股功劳）
3. **不许把 `suspended` 说成 `rejected`。**（测不出 ≠ 没用）
4. **不许在到达 N\* 之前下「有效/无效」结论。**（两笔为负 = 无信息）
5. **不许把「某规则的改善」直接归因于市场状态**，而不先做分年拆解、排掉**数据可用性伪影**（§3.4）。
6. **不许在没做差异笔集合审计之前，宣称某个改动"提高了收益"。**（§3.7）
7. **不许报随机分位而不写零分布口径。**（候选集不同能差 10pp，"过不过 95"会翻，§3.11）
8. **不许不剔一笔/一段就宣称结论成立。**（剔最好一笔后翻负 ⇒ 单事件独扛，§3.12）
9. **不许用关键词建的池直接跑结论** —— 先去污，且**去污前后两列都报**（§3.13）。
10. ★ **不许用低等级证据推翻高等级证据。** 典型形态：用一个**短训练段上的 IC≈0**，
    去否掉一个**外部文档预指定、对本机近似前向**的默认档因子。
    正确表述是「**训练段证不出它有额外信息**」，**不是**「**它没用，可以删**」。
    同理：若某改动"跑不掉怀疑"，**新建 v2 前向验证**，**不许改已冻结的 v1**。
11. ★ **不许跳过池构成敏感度就直接谈"改池更好"。** 先去污（§3.13）→ 再测敏感度（§3.18）；
    摆幅 ≥ 改动幅度 ⇒ 一律写「**不可判定**」，不许写成「更好但样本不够」。**加排除词也要逐个核对命中面。**

## 五、可迁移性测试（旗舰工具）

一句话：**你信的那个指标，和未来同号吗？**
```python
rho = spearman(grid["train_total"], grid["test_total"])   # 见 scripts/fps_factor.py
```

| 历史指标 → 未来指标 | ETF 赛道轮动线 | 潮汐打板线 |
|---|---|---|
| 训练单笔均值 → 留出单笔均值 | +0.116 | **+0.429** |
| 训练链式净值 → 留出链式净值 | +0.116 | +0.233 |
| 训练胜率 → 留出胜率 | — | **+0.756** |
| 全期收益（作弊键）→ 留出 | +0.868 | — |

★ **可迁移性不是策略的属性，是「信号/数据/自由度」的属性。**
同一套算术在两条线上差 3.7 倍 ⇒ **不许把一条线的 ρ 当成另一条线的先验。** ρ < 0.3 ⇒ **不要用该指标选参。**

**先做可分辨性分层，再谈 ρ**：`SE_i = σ_i/√n_i`，层内均值极差 / 平均 SE。
<2 ⇒ 排序不可分辨（「ρ≈0」是测不出，不是不迁移）；>2 才有讨论意义。
实测对照：打板线（仅样本充足配置）**3.88**（留出 4.84）｜打板线事后子集网格 **0.37**。

★ **跨采样频率的 Calmar 不可比**：月频净值看不见月内回撤，会系统性放大 ~2 倍（日频 0.19 vs 月频 0.38）。
★ **固定日历是硬要求**：用「相位自由」的网格会放大 Calmar **3~4 倍**；落地前必须**预先写定不可事后更改的再平衡日历**。
